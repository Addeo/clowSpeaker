Tandem AI Chat - 隐私政策

本隐私政策说明 Tandem AI Chat（“本 App”）如何处理用户数据。

1. 我们是谁

产品：Tandem AI Chat (iOS)

隐私咨询联系方式：

supp0rt.serg@yandex.com

2. 核心隐私立场

在当前架构中，本 App 不会在 Tandem 运营的 backend 上处理或存储您的消息内容。

大多数 App 状态都本地存储在您的设备上。

3. 本 App 处理哪些数据

3.1 本地 App 数据（设备端）

本 App 可能会存储本地配置和运行数据，包括：

  • 引导流程和设置偏好；
  • 所选 AI 目标聊天的元数据；
  • 受监控聊天的元数据；
  • 解析设置（例如 prefix/examples）；
  • 角色/prompts 及相关 UI 状态；
  • 本地状态计数器（例如成功 parse 使用次数）；
  • 为支持导出准备的脱敏诊断日志。

3.2 Telegram 相关数据

本 App 使用 Telegram APIs/TDLib，并基于您自己的配置和账户上下文运行。

与 Telegram 交换的数据受 Telegram 政策处理。

3.3 外部 bots/providers 数据流

如果您选择将内容发送给第三方 bots/providers，您的数据会根据您的操作和设置发送给这些第三方。

这些第三方是遵循其自身条款/隐私规则的独立控制方/处理方。

4. 我们不做什么（当前架构）

本 App 运营方不会：

  • 运行用于存储您消息内容的 Tandem backend；
  • 将来自本 App 的 Telegram 消息数据用于 AI/ML 模型训练或微调。

5. AI/ML 训练限制

通过本 App 处理的 Telegram 消息数据不会被本 App 运营方用于模型训练/微调。

如果您将数据传输给第三方 bots/providers，他们可能会适用自己的保留/训练政策。您需对该传输负责。

6. 日志和支持导出

本 App 可以为支持流程生成脱敏日志导出。

  • 日志会在导出前按已实现的方式进行脱敏。
  • 您可以控制是否发送支持邮件以及发送给谁。
  • 发送邮件会使用您设备上的邮件配置和所选收件人。

7. 法律依据（如适用）

根据司法辖区，处理可能基于：

  • 合同/履行 App 功能；
  • App 运行/安全方面的合法利益；
  • 您对可选权限/功能的同意。

8. 数据保留

本地 App 数据会保留在您的设备上，直到：

  • 您在 App 内删除/重置它（如可用），
  • 或您移除本 App。

第三方服务（Telegram、bots/providers）适用其自己的保留规则。

9. 安全性

本 App 会为本地运行采取合理的技术措施，但任何客户端软件都无法保证绝对安全。

您负责：

  • 保护您的设备，
  • 保护账户凭据和 API access，
  • 避免不安全地共享敏感数据。

10. 儿童

本 App 不适用于未达到适用法律要求年龄的未成年人进行非法使用。

如果您的司法辖区/业务模式要求，请添加年龄门槛和家长同意控制。

11. 国际传输

如果您使用第三方服务，数据可能会根据这些提供商的基础设施/政策在您所在国家/地区以外的司法辖区处理。

12. 本政策的变更

本政策可能会不时更新。

重大变更应随新的生效日期发布。
