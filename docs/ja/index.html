Tandem AI Chat - プライバシーポリシー

このプライバシーポリシーは、Tandem AI Chat（「本アプリ」）がユーザーデータをどのように扱うかを説明します。

1. 運営者について

製品: Tandem AI Chat (iOS)

プライバシーに関するお問い合わせ先:

supp0rt.serg@yandex.com

2. プライバシーに関する基本方針

現在のアーキテクチャでは、本 App は Tandem が運営する backend 上でメッセージ内容を処理または保存しません。

App の状態の大部分は、お使いのデバイスにローカル保存されます。

3. 本 App が扱うデータ

3.1 ローカル App データ（デバイス上）

本 App は、以下を含むローカル設定および運用データを保存する場合があります:

  • オンボーディングと設定のプリファレンス;
  • 選択された AI 送信先チャットのメタデータ;
  • 監視対象チャットのメタデータ;
  • 解析設定（例: prefix/examples）;
  • ロール/prompts および関連する UI 状態;
  • ローカルステータスカウンター（例: 解析の成功使用回数）;
  • サポートエクスポート用に準備されたマスク済み診断ログ。

3.2 Telegram 関連データ

本 App は、お客様自身の設定およびアカウントコンテキストで Telegram APIs/TDLib を使用します。

Telegram と交換されるデータは Telegram のポリシーに基づいて処理されます。

3.3 外部 bots/providers へのデータフロー

お客様が第三者の bots/providers へコンテンツを送信することを選択した場合、お客様のデータはお客様の操作と設定に従ってそれらの相手に送信されます。

それらの第三者は、自らの規約/プライバシールールに基づく独立した管理者/処理者です。

4. 当社が行わないこと（現在のアーキテクチャ）

App の運営者は以下を行いません:

  • お客様のメッセージ内容を保存する Tandem backend を運用すること;
  • 本 App からの Telegram メッセージデータを AI/ML モデルのトレーニングまたはファインチューニングに使用すること。

5. AI/ML トレーニングの制限

本 App を通じて処理される Telegram メッセージデータは、App 運営者によるモデルトレーニング/ファインチューニングには使用されません。

お客様が第三者の bots/providers にデータを転送する場合、それらは独自の保持/トレーニングポリシーを適用することがあります。その転送についてはお客様が責任を負います。

6. ログとサポートエクスポート

本 App はサポートワークフロー用にマスク済みログエクスポートを生成できます。

  • 実装されている場合、ログはエクスポート前にマスクされます。
  • サポートメールを送信するかどうか、および送信先はお客様が管理します。
  • メール送信には、お使いのデバイスのメール設定と選択された宛先が使用されます。

7. 法的根拠（該当する場合）

法域によっては、処理は以下に依拠する場合があります:

  • App 機能の契約/履行;
  • App の運用/安全性に関する正当な利益;
  • 任意の権限/機能に対するお客様の同意。

8. データ保持

ローカル App データは、以下のいずれかまでお使いのデバイスに残ります:

  • お客様が App 内で削除/リセットする（利用可能な場合）,
  • または App を削除する。

第三者サービス（Telegram、bots/providers）は独自の保持ルールを適用します。

9. セキュリティ

本 App はローカル運用のために合理的な技術的措置を適用しますが、いかなるクライアントソフトウェアも絶対的なセキュリティを保証することはできません。

お客様は以下について責任を負います:

  • お使いのデバイスを保護すること,
  • アカウント認証情報と API access を保護すること,
  • 機微データを安全でない方法で共有しないこと。

10. 子ども

本 App は、適用法で求められる年齢に満たない未成年者による違法な使用を意図したものではありません。

お客様の法域/事業モデルで必要な場合は、年齢確認と保護者同意の管理を追加してください。

11. 国際移転

お客様が第三者サービスを使用する場合、データはそれらの提供者のインフラ/ポリシーに基づき、お客様の国以外の法域で処理されることがあります。

12. 本ポリシーの変更

本ポリシーは随時更新される場合があります。

重要な変更は、新しい施行日とともに公開されるべきです。
