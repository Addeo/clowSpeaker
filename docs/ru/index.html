Tandem AI Chat - Политика конфиденциальности

Эта Политика конфиденциальности объясняет, как Tandem AI Chat («Приложение») обрабатывает данные пользователя.

1. Кто мы

Продукт: Tandem AI Chat (iOS)

Контакт для запросов по конфиденциальности:

supp0rt.serg@yandex.com

2. Основная позиция по конфиденциальности

В текущей архитектуре Приложение не обрабатывает и не хранит содержимое ваших сообщений на бэкенде, управляемом Tandem.

Большая часть состояния приложения хранится локально на вашем устройстве.

3. Какие данные обрабатывает Приложение

3.1 Локальные данные приложения (на устройстве)

Приложение может хранить локальную конфигурацию и операционные данные, включая:

  • предпочтения онбординга и настроек;
  • метаданные выбранного AI-чата назначения;
  • метаданные отслеживаемого чата;
  • настройки парсинга (например, префикс/примеры);
  • роли/промпты и связанное состояние интерфейса;
  • локальные счётчики статуса (например, успешное использование парсинга);
  • замаскированные диагностические логи, подготовленные для экспорта в поддержку.

3.2 Данные, связанные с Telegram

Приложение использует Telegram APIs/TDLib с вашей собственной конфигурацией и контекстом аккаунта.

Данные, которыми вы обмениваетесь с Telegram, обрабатываются в соответствии с политиками Telegram.

3.3 Передача данных внешним ботам/провайдерам

Если вы решите отправлять содержимое сторонним ботам/провайдерам, ваши данные отправляются этим сторонам согласно вашим действиям и настройкам.

Эти третьи лица являются независимыми контролёрами/обработчиками по своим условиям и правилам конфиденциальности.

4. Что мы не делаем (текущая архитектура)

Оператор Приложения не:

  • запускает бэкенд Tandem, который хранит содержимое ваших сообщений;
  • использует данные сообщений Telegram из этого Приложения для обучения или дообучения AI/ML-моделей.

5. Ограничение обучения AI/ML

Данные сообщений Telegram, обрабатываемые через это Приложение, не используются оператором Приложения для обучения или дообучения моделей.

Если вы передаёте данные сторонним ботам/провайдерам, они могут применять собственные правила хранения и обучения. Вы несёте ответственность за такую передачу.

6. Логи и экспорт для поддержки

Приложение может создавать замаскированные экспорты логов для поддержки.

  • Логи маскируются перед экспортом там, где это реализовано.
  • Вы контролируете, отправлять ли письмо в поддержку и кому.
  • Отправка письма использует почтовую конфигурацию вашего устройства и выбранного получателя.

7. Правовое основание (где применимо)

В зависимости от юрисдикции обработка может основываться на:

  • договоре/исполнении функций приложения;
  • законных интересах в работе и безопасности приложения;
  • вашем согласии для необязательных разрешений/функций.

8. Хранение данных

Локальные данные приложения остаются на вашем устройстве, пока:

  • вы не удалите/сбросите их в приложении (где доступно),
  • или не удалите приложение.

Сторонние сервисы (Telegram, боты/провайдеры) применяют собственные правила хранения.

9. Безопасность

Приложение применяет разумные технические меры для локальной работы, но ни одно клиентское ПО не может гарантировать абсолютную безопасность.

Вы отвечаете за:

  • защиту вашего устройства,
  • защиту учётных данных и доступа к API,
  • избежание небезопасной передачи чувствительных данных.

10. Дети

Приложение не предназначено для незаконного использования несовершеннолетними младше возраста, требуемого применимым законодательством.

Если это требуется вашей юрисдикцией/бизнес-моделью, добавьте проверку возраста и механизмы родительского согласия.

11. Международные передачи

Если вы используете сторонние сервисы, данные могут обрабатываться в юрисдикциях за пределами вашей страны в рамках инфраструктуры/политик этих провайдеров.

12. Изменения политики

Эта Политика может время от времени обновляться.

Существенные изменения следует публиковать с новой датой вступления в силу.
